# Security Policy

## Supported Versions

The latest release is actively maintained. Please ensure you're using the most recent version for best performance and security.

| Version | Supported          |
|---------|--------------------|
| Latest  | ✅                 |
| Older   | ❌                 |

## Reporting a Vulnerability

If you discover a security vulnerability or suspect a potential issue, please report it by opening a [GitHub Issue](../../issues) in this repository.

To help us investigate, please include:
- A clear description of the issue
- Steps to reproduce (if applicable)
- Any relevant screenshots, logs, or context

Please **do not** submit sensitive information (e.g., passwords, personal data) in your report.

This project does **not handle private user data**, and is intended as a local utility application.

---

Thank you for helping improve the security and reliability of this project!
